DESCRIPTION:
This web platform showcases the historical identity, climate, and spatial data of Bandarawela, Sri Lanka. It features an interactive Leaflet GIS map with toggleable spatial layers, demographic charts, evolution sliders, and a complete data extraction repository.

HOW TO RUN:
1. Ensure all media assets, data files, and scripts are placed in their respective subfolders ('js/', 'data/', 'assets/').
2. Open 'index.html' in any modern web browser or use the Live Server extension in VS Code.

DATA SOURCES:
- Spatial vector points, roads, and boundaries mapped via OpenStreetMap & CARTO basemaps.
- Historical imagery and demographic records compiled for urban informatics analysis.
